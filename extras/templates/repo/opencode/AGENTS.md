# Repository Guidelines

- Keep changes small and focused.
- Match the existing structure and naming patterns in the repo.
- Prefer actionable feedback over style-only nits.
- Call out missing tests when behavior changes.
- Flag imports, folders, or patterns that do not match local conventions.

# PR Review Focus

- Review only the changes introduced by the pull request.
- Prioritize correctness, regressions, and maintainability.
- Cite specific files when suggesting follow-up work.
