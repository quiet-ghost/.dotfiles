# CONTEXT.md Format

```md
# {Context Name}

{One or two sentences describing this context.}

## Language

**Order**:
A request for fulfillment from a customer.
_Avoid_: Purchase, transaction
```

Be opinionated, keep definitions to one or two sentences, and define what a term is. Include only project-specific concepts; group terms under subheadings when useful.

If `CONTEXT-MAP.md` exists, use it to locate multiple context glossaries and describe their relationships there. Otherwise use one root `CONTEXT.md`, created lazily when the first term is resolved.
