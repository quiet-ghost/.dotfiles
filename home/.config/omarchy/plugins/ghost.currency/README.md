# Currency

USD/JPY converter for the Omarchy bar. Rates come from [Frankfurter](https://frankfurter.dev) (central-bank data, no API key).

Bar:

- left click: converter
- right click: swap direction
- middle click: refresh rates

Panel: type an amount, pick USD/JPY/EUR/GBP, swap, and convert. Pair and amount persist in `~/.local/state/omarchy/currency.json`.
