# Currency

Currency converter for the Omarchy bar. Rates come from [Frankfurter](https://frankfurter.dev) (central-bank data, no API key).

Bar:

- left click: converter
- right click: swap direction
- middle click: refresh rates

Panel: type an amount, pick USD/JPY/EUR/GBP/ARS, swap, and convert. Argentine pesos display as `AR$` to distinguish them from USD. Pair and amount persist in `~/.local/state/omarchy/currency.json`.
