# Govee Lights

Omarchy bar widget for the existing `govee-lights` TUI.

The TUI stays the full app. This widget talks to the same Govee cloud API
through `govee-lights-cli`, using `~/.config/govee-lights/.env`.

Bar:

- left click: panel
- right click: power toggle
- middle click: refresh

Panel: power, brightness, device picker, color swatches, white presets, scenes.
