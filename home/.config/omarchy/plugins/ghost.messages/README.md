# ghost.messages

Local Omarchy bar widget for quick access to Slack, Signal, and Vesktop.

- Shows previews from Omarchy's existing ten-item notification history.
- Highlights apps whose Hyprland window requests attention.
- Focuses an existing app window or launches its desktop entry.
- Reads no app database and requires no message API token.

Notification previews are rendered as plain text. Clicking a preview opens its
app; persisted notification actions cannot be replayed after the sender closes
them.
